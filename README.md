# SA_UnitMarks

《心灵终结》3.3.6 的单位头顶标记插件。

| 标记 | 单位 |
|---|---|
| 原生感叹号气泡 | 恐龟加农炮及其变体、幻影坦克、幻光火箭炮、已部署的 EMP／基因／冷冻地雷、两种飓风潜艇、海豚、巨型乌贼、食人鱼潜艇、鹦鹉螺潜艇 |
| 红色感叹号 | 钻地运输车、怒焰地雷、M.A.D. 地雷、自爆卡车、自爆吉普车、友川纪夫及其他步兵英雄 |
| 红色骷髅 | 暴君、虫群女王、阿库拉、瘟神、各类间谍、斯大林之拳（含展开形态）、百夫长、毒蜥、基洛夫 |
| 红色骷髅（英雄乘员在车内时） | 斯特瑞克 IFV、执政官 AMC、长剑步兵装甲 |

## 安装

构建后，将 `dist/SA_UnitMarks.dll` 放到 `gamemd.exe` 和 `Syringe.exe` 所在目录，从游戏客户端启动。卸载时移走 DLL。

## 构建

使用 Python 3 和 32 位 MinGW-w64（`i686-w64-mingw32`）。将工具链的 `bin` 目录加入 `PATH`，或设为 `MOE_MINGW`，然后运行 `python build.py`。
